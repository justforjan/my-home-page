# My personal website

The original goal of the project was not to build a personal website but to learm full-stack development including frontend, backend and infrastructure. You can reach the website under [justforjan.eu](https://justforjan.eu)

Tools and technologies used:
- React.js as the frontend framework
- TailwindCSS for frontend styling
- FastAPI as the backend framework
- PostgreSQL 
- MinIO as an object storage
- GitHub Actions for automatic deployment
- Docker and docker-compose for containarization and deployment


This is a very simple web application and I know there are plenty of ways to improve it. Here is a list of improvements I have been thinking about:

- Backend Authentication
- Secrets Management
- Automatic Update of dependencies (Renovate Bot)
- Deploy with Kubernetes (fingers crossed I have some time during the semester break to dive into Kubernetes)
